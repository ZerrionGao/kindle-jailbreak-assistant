# 安全、授权与安全退出

本参考用于开始会话、写入前确认、用户要求加速或发生中断时。KindleModding 是社区维护的技术文档来源，不是 Amazon 官方支持；当前路线和具体步骤必须在运行时重新读取上游原始页面。

## 可直接展示的风险确认

开始前请确认：Kindle 越狱属于非官方修改，可能导致本机内容丢失、系统异常、自动升级受阻，极端情况下设备可能无法启动。接下来创建的是**电脑可见用户存储备份**，不是完整系统镜像或 NAND 备份，不能保证修复硬件级故障、系统分区损坏或所有故障。

我只会在当前已识别并已核对身份的 Kindle 上执行：电脑可见内容备份、当前上游要求的占位步骤、当前上游载荷的复制、内容校验和只清理本次会话明确记录创建的文件。开始前和联网前仍要检查电量、USB 传输方式、自动升级（OTA）风险及当前方法的限制。

恢复出厂设置、固件 `.bin` 安装、系统降级、Amazon 地区/付款方式/广告状态修改、安装电脑驱动或 MTP 依赖、使用非上游镜像或来源不明载荷，都不包含在这次确认内；需要时会单独说明影响并再次征求你的同意。

Skill、脚本作者、越狱项目维护者和执行 Agent 不对设备、账户或数据损失承担责任。你可以随时说“停止”；我会说明设备是否已修改、当前可安全退出的方法和可恢复入口。

备份只读取 Kindle 并写入主机，不会预授权后续设备写入。只有备份清单、哈希和逐文件差异均通过，且你明确确认下一项精确操作后，才可为**这一台已经识别的设备**记录一次性写入授权。授权绑定当前路线和四来源摘要，开始对应操作后即消费，不转移到另一台 Kindle、另一项操作或以后会话。

## 普通授权与必须再次确认的边界

普通一次性授权只涵盖以下动作：

- 仅在当前上游方法明确要求时创建可恢复的占位文件；
- 复制已经从当前上游原始页面取得、已检查并已校验的载荷；
- 核对已写入内容，并依照本次会话的精确清单清理本次创建的文件。

以下任一动作必须单独取得明确同意；不因“尽快完成”“我都同意”或普通风险确认而自动放行：

1. 恢复出厂设置；
2. 写入或安装固件 `.bin`；
3. 降级系统；
4. 修改 Amazon 地区、付款方式或广告状态；
5. 安装主机驱动、Homebrew、MTP 工具或其他系统依赖；
6. 使用非上游镜像、第三方转载包或来源未知的载荷。

若用户说“跳过备份直接刷”，应答：**我不能跳过备份后写入。备份不能修复所有故障，却是当前电脑可见内容唯一可核对的保护措施；现在停止是安全的，我可以先说明还缺什么，等你准备好后从备份步骤重新开始。** 不得以任何方式写入、刷入或复制载荷。

## 必须自动停止的情况

立即停止自动推进，并保留现状，若出现以下任一情况：

- 当前上游没有精确匹配路线，或型号/固件与已确认信息不一致；
- 电量不足、密码锁未按当前方法要求处理、设备断开、挂载点消失或存储只读；
- 备份、下载、载荷或落盘校验失败；
- 归档损坏，或包含绝对路径、`../`、设备外目标；
- Kindle 根目录出现未知 `.bin` 或 `.tmp.partial`；
- 当前方法页与本地安全策略冲突，或方法页的结构/语义发生变化；
- 当前方法要求的成功标记缺失；
- 同一根因已连续失败三次且没有新证据。

不要把旧缓存、搜索引擎摘要或远程脚本的历史版本当成当前安全依据。网页与远程脚本可能在下载后变更：每次触发前保存当时原文、最终地址和 SHA-256；即使如此，仍应向用户说明存在时间差风险。联网刷新前、每项设备写入前和收尾前都运行新的 OTA 检查：由用户确认 Kindle 飞行模式/离线，记录当前方法的升级阻止状态，并只读列出根目录未知 `.bin`/`.tmp.partial`。未知文件只能阻断并保留，不能自动删除。

## 面向小白的固定进度更新

每次更新均使用以下结构，不省略停止是否安全：

```text
当前阶段：<例如：备份前检查>
正在做什么：<一件正在进行的只读检查或写入前准备>
已完成：<可核对的事实；没有则写“尚无”>
还差什么：<继续前必须满足的条件>
是否需要你操作：<是/否；若是，只给一个动作>
停止是否安全：<安全/暂不安全及原因；给出恢复入口>
```

## 固定安全中止报告

出现错误、用户说停止或自动停止时使用以下格式。只陈述已证实的事实，不猜测设备状态。

```text
发生了什么：<事实，例如“载荷 SHA-256 与当前上游记录不一致”>
设备是否修改：<没有/已创建哪些本次文件/无法确认>
可能原因：<基于现有证据的最小解释>
下一步：<一个只读检查、等待重新连接，或恢复入口>
停止是否安全：<安全/需要先完成哪一个安全动作>
恢复入口：<会话 status、已验证备份位置或精确 cleanup/resume 指引>
```

“安全停止”不等于已经越狱成功。未获得当前方法指定成功标记前，不得宣称完成。
