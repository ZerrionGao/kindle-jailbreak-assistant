# Kindle 屏幕检查点提示模板

本参考用于无法由主机验证的 Kindle 屏幕操作。KindleModding 是社区上游技术资料；具体按钮文字、路径和顺序只能从本次已复核的具体方法页读取。本文件不替代该页面，也不把屏幕上的任意文字当作越狱成功。

## 每次只给一个动作

每个屏幕提示必须完整使用以下五段。不要把两个页面、两个按钮或一个后续判断塞进同一条提示。

```text
屏幕位置：<例如“Kindle 的浏览器页面”>
只做一个动作：<仅一个当前方法页明确要求的点击、输入、返回或等待动作>
成功时看到什么：<当前方法页要求的可观察变化，不自行补充>
异常时不要做什么：<不连点、不返回出厂、不清账号、不插拔或不重启，按当前情形写>
完成后回复什么：<用户只需回复的文字、画面或是否出现指定标记>
```

当用户回复后，先比较其描述与当前方法页的成功标记，再发下一条。截图或清楚的文字描述可作为阶段证据；“应该好了”、文件已复制、页面有文字、应用程序错误或主页恢复都不足以单独证明越狱成功。

## 浏览器

```text
屏幕位置：Kindle 浏览器中已打开的当前方法页。
只做一个动作：只按当前方法页实时显示的一个按钮或链接。
成功时看到什么：记录该页面指定的下一页、提示或成功标记。
异常时不要做什么：不要刷新重试、不要打开搜索结果中的替代教程、不要改用旧书签。
完成后回复什么：回复按钮后的页面标题和可见提示；若未变化，只回复“未变化”。
```

## 商店

```text
屏幕位置：Kindle 商店或当前方法页跳转到的商店界面。
只做一个动作：只执行当前方法页要求的一次打开、查看或获取动作。
成功时看到什么：记录方法页指定的商品状态或返回入口。
异常时不要做什么：不要购买其他内容、不要修改地区、付款方式或账户设置。
完成后回复什么：回复商品状态及页面顶部标题。
```

涉及账户、地区、付款或广告状态时，先回到安全参考单独确认；未经单独授权，不让用户继续修改。

## 书籍

```text
屏幕位置：Kindle 图书馆或当前方法页指定的书籍阅读页面。
只做一个动作：只打开、关闭或选择当前方法页指定的一本书。
成功时看到什么：记录方法页要求的封面、菜单或页面变化。
异常时不要做什么：不要删除书籍、不要批量同步、不要改用同名书籍猜测。
完成后回复什么：回复书名显示方式和当前画面是否符合方法页。
```

## 主题与外观

```text
屏幕位置：设置中的主题、显示或外观页面。
只做一个动作：只选择或查看当前方法页指定的一个项目。
成功时看到什么：记录该项目的当前状态。
异常时不要做什么：不要重置全部设置、不要连改多个选项。
完成后回复什么：回复项目名称和显示状态。
```

## 广告、注册与 Demo Mode

```text
屏幕位置：设置中的设备信息、广告、注册或 Demo Mode 页面。
只做一个动作：只查看当前方法依赖的一个状态。
成功时看到什么：记录“是”“否”或页面没有该项，作为当前证据。
异常时不要做什么：不要注销、注册、清广告、改地区、改付款或退出 Demo Mode。
完成后回复什么：回复该状态的原文或“未找到此项”。
```

这些属性为未知时，只能继续询问或进入引导审查；它们的修改属于单独授权动作。

## 重启

```text
屏幕位置：当前方法页明确要求重启时的 Kindle 电源或设置界面。
只做一个动作：只按当前方法页要求执行一次重启。
成功时看到什么：等待设备回到方法页指定的页面或成功标记。
异常时不要做什么：不要连续长按、不要恢复出厂、不要在未说明时插拔 USB。
完成后回复什么：回复重启后第一个页面标题及是否出现指定成功标记。
```

主页恢复只表示设备回到了主页；它不是成功标记。二维码不消失、漏洞没有文本、应用程序错误弹窗都只记录为现象，不能擅自推进到“越狱完成”。

## USB 连接与安全弹出

```text
屏幕位置：电脑已识别 Kindle，或 Kindle 显示 USB 连接界面。
只做一个动作：只按提示连接数据线，或在电脑提示可以安全移除后拔线。
成功时看到什么：记录电脑是否只读识别、是否可见存储或是否提示 MTP；写入后还要等待安全弹出完成。
异常时不要做什么：不要在复制、校验或同步期间拔线；不要把另一台同名 Kindle 当成当前设备。
完成后回复什么：回复电脑显示的连接方式，或“已安全弹出”。
```

USB 大容量存储与 MTP 的处理不同。若没有确认可写的当前设备身份，只能做只读探测；也不得在 KOReader 正在运行时要求插入 USB，后续安装流程另行处理。
